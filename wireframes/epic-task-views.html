Epic board: Cards or Rows

This adds one switch to the epic board you already approved. Cards is today's kanban. Rows lists the same tasks with one collapsible section per status, in workflow order. The filters, "Task in epic", and the epic's description and files are the same in both. The wireframe is low-fidelity, and the red numbers point to the notes.

Notes

  1. Fixed columns so you can scan down the list: ID, title, flags and label, due date, subtasks done, assignee. On narrow windows the subtasks and due columns are dropped first.
  2. Each status is a section, in workflow order, with its colour dot and count. Click the header to collapse or expand it. When collapsed, the header still shows a summary ("1 blocked · 1 overdue"), so nothing stuck is hidden.
  3. Drag a row to reorder it, or drop it into another section to move it to that status. The same rules as the board apply: a blocked task can't move forward.
  4. Add task in a section creates the task in this epic, already in that status. It's an inline title field, like the subtask list.
  5. Done starts collapsed. Which sections are open is remembered per epic.
Clicking a row opens the same task dialog as clicking a card.

Notes

  1. Status pill on hover or focus lets you move a row without dragging, using keyboard or touch. Columns the task can't move to (it's blocked) are shown but disabled, with the reason.
  2. The drop slot shows where a dragged row will land, in this section or another one.
  3. Empty sections stay listed as a single folded line, so the workflow is always complete and you can still drop a task into them.
  4. Filters work the same as in Cards. Sections only count the tasks shown.
  5. On a phone each row is two lines: title and avatar, then flags, ID and subtasks. Rows read better than swiping sideways through columns, so Rows is the default on phones until you pick otherwise.
